# Legacy QMK layouts

These files preserve older QMK Configurator layouts from before the Eyelash Corne became the active keyboard:

- `idobo.layout.json` — Idobo/XD75-style ortholinear layout
- `redox_w.layout.json` — Redox Wireless layout

They are not consumed by the ZMK build or Nick Coutsos' ZMK Keymap Editor. Import them into [QMK Configurator](https://config.qmk.fm/) only when working with the corresponding legacy keyboard.
